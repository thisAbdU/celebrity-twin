You are generating questions for a fun web game called "Celebrity Twin".

The game tries to match a player with a celebrity based on their personality, behavior, habits, and choices.

This is NOT a scientific personality test. The questions should feel entertaining, relatable, surprising, and conversational.

Generate EXACTLY 50 unique questions.

IMPORTANT:
- Do NOT generate IDs. The Python script will assign unique IDs later.
- Return ONLY valid JSON.
- Do NOT include Markdown.
- Do NOT include explanations outside the JSON.
- Every question must have exactly 4 answer choices.
- Every answer must contain trait weights.
- Questions should be understandable without additional context.
- Avoid repetitive question structures.

Use only these traits:

- adventure

- spontaneity

Trait weights must be numbers from 0.0 to 1.0.

--------------------------------------------------
QUESTION STYLE
--------------------------------------------------

Questions should feel like fun conversation rather than a personality questionnaire.

Prefer:
- hypothetical situations
- funny dilemmas
- unexpected situations
- everyday behavior
- social situations
- work situations
- technology culture
- developer/workspace culture
- internet culture
- decision-making
- mildly chaotic situations
- "what would you do?" scenarios
- situations where there is no obviously correct answer

Avoid boring questions such as:

- What's your favorite color?
- Are you introverted or extroverted?
- What's your favorite food?
- Do you like music?
- Are you hardworking?

Instead, reveal personality indirectly through choices.

Each answer should map to different personality traits.
